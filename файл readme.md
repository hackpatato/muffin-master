##  Обзор

**Muffin Master** — это платформа управления и контроля (C2) с открытым исходным кодом, разработанная для исследований в области кибербезопасности, академических исследований и санкционированных учений «красной команды». Созданная с учетом принципов облегченной архитектуры, она предоставляет интуитивно понятный интерфейс для управления активными сессиями и эффективного запуска модулей, используемых на этапе после эксплуатации.


---

##  Особенности

* **Модульная архитектура:** простое расширение функциональных возможностей с помощью пользовательских модулей.
* **Скрытая связь:** гибкие транспортные каналы, предназначенные для моделирования реального поведения злоумышленников.
* **Управление сессиями:** отслеживание и контроль подключенных имплантов/агентов в режиме реального времени.
* **Незначительная нагрузка:** низкое потребление ресурсов как на сервере, так и в целевой среде.
